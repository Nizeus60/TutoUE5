🔧 Fusion d'objets avec Procedural Mesh

🎯 Niveau : Intermédiaire ⏱️ Durée : ~30 minutes 📦 Unreal Engine 5.7 🔤 Langage : Blueprint
ℹ️

Ce que tu vas apprendre

Dans ce tutoriel, tu vas créer un système de fusion d'objets physiques qui combine plusieurs meshes en un seul mesh procedural. Le système supportera la fusion récursive (fusionner des objets déjà fusionnés) et permettra de "défaire" une fusion en respawnant les objets originaux.

#1. Le problème avec la méthode par attachement

Quand on fusionne des objets en les attachant simplement comme composants, plusieurs problèmes apparaissent :

  • Performances : Chaque composant = un calcul de physique séparé
  • Collisions : Les parties peuvent entrer en collision entre elles
  • Complexité : La fusion récursive devient un cauchemar de hiérarchie
  • Maintenance : Difficile de débugger avec des dizaines de composants
⚠️

Expérience vécue

J'ai essayé cette méthode au début et j'ai eu des problèmes avec les objets qui disparaissaient lors de fusions multiples. Le système devient rapidement ingérable !

#2. La solution : Procedural Mesh

La Procedural Mesh Component permet de créer un mesh dynamiquement en combinant les vertices de plusieurs meshes. Résultat : UN SEUL mesh, une seule collision, une seule physique.

Avantages

Critère Méthode Attach Procedural Mesh
Nombre de composants N composants 1 composant
Calculs physiques N calculs 1 calcul
Fusion récursive Compliqué 😰 Trivial 😊
Performances Moyennes Excellentes
Défaire fusion Difficile Facile (respawn)

#3. Architecture du système

Le système se compose de trois éléments principaux :

BP_MasterObjet

Ton Blueprint de base pour tous les objets "simples" (bâton, caillou, etc.). Il contient le mesh et les propriétés de l'objet.

BP_MasterObjetFusion

Blueprint pour les objets fusionnés. Il hérite de BP_MasterObjet et ajoute le Procedural Mesh Component + l'array de données des parties.

Struct FusionPartData

Structure de données qui sauvegarde toutes les infos d'un objet avant fusion (mesh, transform, variables).

#4. Créer le struct de données

D'abord, crée un Blueprint Structure pour sauvegarder les données de chaque partie fusionnée.

📝 Blueprint Structure : FusionPartData 
Struct FusionPartData:
├─ StaticMesh (Static Mesh Object Reference)
├─ RelativeTransform (Transform)
├─ Material (Material Interface Object Reference)
├─ Durability (Float)
├─ ObjectType (String)
└─ CustomData (Map of String to String) // Optionnel
💡

Astuce

Tu peux ajouter autant de variables que nécessaire dans ce struct. Pense à toutes les propriétés que tu veux conserver quand tu défais la fusion !

#5. Implémentation Blueprint

Prérequis : Activer le plugin

📦

Plugin requis

Avant de commencer, assure-toi d'activer le plugin "Procedural Mesh Component" dans :

Edit → Plugins → Rechercher "Procedural Mesh" → Cocher "Enabled"

Redémarre Unreal Engine après l'activation.

Créer BP_MasterObjetFusion

Créer le Blueprint

Crée un nouveau Blueprint Class qui hérite de BP_MasterObjet.
Nomme-le BP_MasterObjetFusion.

Ajouter le Procedural Mesh Component

Dans le Components panel, ajoute un Procedural Mesh Component.
Nomme-le ProceduralMesh.

Créer les variables

Dans le panneau Variables, crée :
• PartsData (Array of FusionPartData)
• IsFused (Boolean) - pour savoir si l'objet est fusionné

#6. La fonction de fusion

Maintenant, créons la fonction qui combine plusieurs objets en un seul mesh procedural.

Function : FuseObjects

⚙️ Blueprint Function : FuseObjects 
Input:
├─ ObjectsToFuse (Array of BP_MasterObjet)

Logic:
1. Pour chaque objet dans ObjectsToFuse:
   ├─ Créer un FusionPartData
   ├─ Sauvegarder: Mesh, World Transform, Material, Variables
   └─ Ajouter à PartsData array

2. Pour chaque FusionPartData dans PartsData:
   ├─ Récupérer les vertices du mesh
   ├─ Transformer selon RelativeTransform
   └─ Ajouter au Procedural Mesh Component

3. Créer la collision du mesh combiné

4. Activer la physique sur ProceduralMesh

5. Détruire tous les objets originaux

6. Set IsFused = true

Détails d'implémentation

⚠️

Point important

Quand tu récupères les vertices d'un Static Mesh, tu dois les transformer dans l'espace monde (World Space) AVANT de les combiner, sinon les positions seront incorrectes.

🔧 Pseudo-code pour combiner les meshes 
// Arrays finaux pour le mesh combiné
FinalVertices = []
FinalTriangles = []
FinalNormals = []
FinalUVs = []

VertexOffset = 0

Pour chaque PartData dans PartsData:
  // 1. Récupérer les données du mesh source
  SourceMesh = PartData.StaticMesh
  SourceVertices = GetVertices(SourceMesh)
  SourceTriangles = GetTriangles(SourceMesh)
  SourceNormals = GetNormals(SourceMesh)
  SourceUVs = GetUVs(SourceMesh)
  
  // 2. Transformer chaque vertex
  Pour chaque Vertex dans SourceVertices:
    TransformedVertex = TransformPosition(Vertex, PartData.RelativeTransform)
    FinalVertices.Add(TransformedVertex)
  
  // 3. Ajuster les indices des triangles
  Pour chaque Triangle dans SourceTriangles:
    AdjustedTriangle = Triangle + VertexOffset
    FinalTriangles.Add(AdjustedTriangle)
  
  // 4. Copier les normales et UVs
  FinalNormals.Append(SourceNormals)
  FinalUVs.Append(SourceUVs)
  
  // 5. Mettre à jour l'offset
  VertexOffset += SourceVertices.Length

// 6. Créer le mesh procedural
ProceduralMesh.CreateMeshSection(
  SectionIndex = 0,
  Vertices = FinalVertices,
  Triangles = FinalTriangles,
  Normals = FinalNormals,
  UV0 = FinalUVs,
  VertexColors = [],
  Tangents = [],
  bCreateCollision = true
)
🔥

Attention : Limitations Blueprint

En Blueprint pur, il est difficile d'accéder directement aux vertices d'un Static Mesh. Tu as deux options :

  1. Utiliser du C++ pour créer une fonction Blueprint-callable qui récupère les vertices
  2. Utiliser Geometry Script (plugin UE5) qui permet de manipuler les meshes en Blueprint

#7. Défaire une fusion

La beauté de ce système : défaire une fusion est trivial ! Tu respawnes simplement les objets originaux à partir des données sauvegardées.

Function : UnfuseObjects

⚙️ Blueprint Function : UnfuseObjects 
Logic:

1. Si IsFused == false:
   └─ Return (rien à défaire)

2. Pour chaque PartData dans PartsData:
   ├─ Spawn Actor (BP_MasterObjet)
   ├─ Set Static Mesh = PartData.StaticMesh
   ├─ Set World Transform = PartData.RelativeTransform
   ├─ Set Material = PartData.Material
   ├─ Set Durability = PartData.Durability
   └─ Set ObjectType = PartData.ObjectType

3. Destroy Self (l'objet fusionné)
💡

Variante : Explosions

Tu peux rendre la défusion plus cool en ajoutant une force physique quand tu respawnes les objets ! Ça crée un effet d'explosion sympathique.

#8. Optimisations

Performances

  • LODs : Si tes meshes originaux ont des LODs, conserve-les dans le mesh procedural
  • Collision simplifiée : Utilise une collision box/sphere pour le mesh combiné au lieu d'une collision complexe
  • Limite le nombre de parties : Au-delà de 10-15 objets fusionnés, les performances peuvent chuter
  • Materials : Si possible, utilise le même material pour tous les objets fusionnés (évite les draw calls multiples)

Mémoire

🧹 Nettoyage mémoire 
// Après avoir créé le Procedural Mesh, pense à clear les arrays
FinalVertices.Clear()
FinalTriangles.Clear()
FinalNormals.Clear()
FinalUVs.Clear()

// Garbage collector fera le reste

#9. Problèmes courants

❌ Le mesh combiné n'apparaît pas

  • Vérifie que le plugin Procedural Mesh est activé
  • Assure-toi que les vertices sont bien transformés en World Space
  • Check que les triangles sont dans le bon ordre (winding)

❌ Les collisions ne marchent pas

  • Vérifie que bCreateCollision = true dans CreateMeshSection
  • Essaye d'utiliser SetCollisionEnabled(Enabled) après création
  • Active Simulate Physics sur le ProceduralMesh component

❌ Les textures sont bizarres

  • Vérifie que tu copies bien les UVs de chaque mesh
  • Les UVs doivent être normalisés (entre 0 et 1)

❌ Crash lors de la fusion

  • Vérifie que les arrays Vertices/Triangles/Normals/UVs ont la bonne taille
  • Les indices de triangles doivent être < nombre de vertices
  • Ne pas avoir de vertices ou triangles vides
